# Repository instructions

Read README.md and specs/_readme.md first. Work in this checkout on main and preserve existing work.
Keep current contracts in specs/; design/ owns planned choices. Keep local milestone notes outside the repository.
README.md is the single source of truth for the categorized mod list; edit it directly. Do not add a duplicate JSON catalog, release generator or download service.
List only the maintainer's own mods and explicitly approved external mods with confirmed author permission. Do not discover and add community listings merely because their repositories are public.
Use installed Python 3.11+ for the lightweight index check. Do not download dependencies automatically.
Run python3 tools/check.py before reporting completion; report skipped gates and failures accurately.
Keep game binaries, extracted assets, saves, credentials and generated output under ignored local/ or artifacts/.
No push, publication, remote creation, PR creation or project license without a user request.
Before acquiring or updating external material, read ~/.codex/skills/external-intake/SKILL.md and complete its review.
