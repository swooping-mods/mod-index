# Mod Index specs

`swooping-mods/mod-index` is a player-facing directory of Moon Sweepers mods and tools. The categorized list is maintained directly in README.md.

| Spec | Owning source | Read when |
|---|---|---|
| [Directory and contribution rules](catalog.md) | `README.md`, `CONTRIBUTING.md`, `tools/check.py`, `.github/` | Editing categories, listings, contribution guidance or the lightweight index check |

Local milestone notes and retired pipeline evidence stay outside the repository. The API and loader own their own packaging and release workflows.
