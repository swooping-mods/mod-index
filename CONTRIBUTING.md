# Add or update a listing

This index lists the maintainer's own mods and external mods included with their authors' explicit permission. Public availability alone does not qualify a mod for listing.

Edit the categorized list in [README.md](README.md) and open a pull request. The maintainer must approve additions; external listings also require confirmation of the author's permission. Keep private permission correspondence out of the public repository.

- Link directly to the author's public repository.
- Confirm maintainer ownership or explicit author permission before adding a listing.
- Add one bullet with the mod name, repository link and a short description.
- Choose the closest category and avoid duplicate listings or mirrors.
- Keep downloads, setup instructions, compatibility details and gameplay support in the author's repository. A Nexus release is optional.

Run `python3 tools/check.py` to check categorized entries, duplicate links and local references. No packages need to be installed. The check runs offline; confirm that a newly added repository is publicly accessible before submitting.

Report broken links or listing corrections here. Report problems with a mod in that mod's repository.
